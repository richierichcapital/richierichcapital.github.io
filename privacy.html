Privacy policy: GM Research Scripts

Effective 7 November 2026.

GM Research Scripts is a private tool used only by its owner, on their own laptop, with their own Google account. It is not offered to anyone else.

Google data it accesses

It uses the drive.file permission, so it can only reach files it created or the owner chose to open with it. These are backup folders and files, and a Google Sheet with a read-only copy of the owner's research database and tabs where the owner types requests. It also reads the email address of the signed-in account, to confirm it is using the right account. It cannot see the owner's other Drive files.

How that data is used

The data is used only to run the tool: to write backups, to update the Sheet and to read the owner's requests. It is not used for advertising, and it is not sold. It is not used to train AI or machine-learning models.

Where it is stored and shared

  • The sign-in is stored on the owner's laptop in Windows Credential Manager.
  • The tool's files remain in the owner's Google Drive.
  • Requests the owner types into the Sheet are copied to the owner's private GitHub repository, as part of the same research project. AI tools the owner uses on that repository, such as Claude, may process them.
  • The tool does not share Google data with anyone else.

Google's requirements

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can remove the tool's access at any time from the Google Account connections page, and can delete its files from Drive.
